## Official versions

The versions of NXDock are built by the workflow of this repository from a tag, and their checksums (SHA256SUMS.txt) are signed with the key of NXDock (SHA256SUMS.txt.minisig), which NXDock checks before it installs a new version of itself.

Only that workflow builds NXDock with its name and its icon (the CMake option `NXDOCK_OFFICIAL`). A program built from this code in any other way is an unofficial build: the Homebrew Menu and its HOME menu shortcut call it "NXDock (unofficial build)", and it has a plain icon.

Problems with a modified version go to whoever made it: the issues and the Discord server of NXDock are for the official versions.
